# Integración de API
El frontend consume únicamente `NEXT_PUBLIC_API_URL` (predeterminado `http://localhost:8000/api`). Contrato completo en el repositorio backend: `GestorDeTarea_Backend/API_CONTRACT.md`. Fechas ISO `YYYY-MM-DD`; JWT Bearer guardado solo en memoria de sesión del navegador. La interfaz usa autenticación, cursos, revisiones y documentos guardados, análisis multipart de PDF, confirmación explícita, y creación, edición y estado de actividades. El backend requiere la migración `sql/migrations/004_frontend_features.sql` para estas rutas.
